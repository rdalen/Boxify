# 🗺 Roadmap

## 🧠 Vision

The goal of Boxify is to become a reusable **Parametric Electronics Enclosure Framework (PEEF)** that enables makers and engineers to generate professional electronics enclosures with minimal manual CAD work.

The long-term vision is to separate electronics design from enclosure design while keeping both fully parametric and reusable.

---

# 🎯 Guiding Principles

Future development of Boxify follows these principles:

- Modular architecture
- Parametric first
- Reusable components
- Stable references
- Measured geometry over manual dimensions
- Simple user configuration
- Extensible library-based design

---

# 🏁 Long-Term Goal

The ultimate goal is for Boxify to become a complete framework for developing custom electronics enclosures.

The desired workflow is simple:

```text
Design PCB
      │
      ▼
Export STEP
      │
      ▼
Import Passenger
      │
      ▼
Configure Boxify
      │
      ▼
Generate Enclosure
      │
      ▼
3D Print
      │
      ▼
Assemble
```

From a single PCB design to a finished enclosure with as little manual CAD work as possible.
