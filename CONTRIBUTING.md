# 🤝 Contributing

First of all, thank you for your interest in Boxify!

Boxify is currently developed as a personal open-source project, but feedback, ideas and contributions are always welcome.

---

# 💡 Ways to Contribute

You can help improve Boxify by:

- Reporting bugs
- Suggesting new features
- Improving the documentation
- Testing new releases
- Sharing example projects
- Proposing improvements to the framework architecture

---

# 🐞 Reporting Issues

When reporting an issue, please include:

- Boxify version
- Onshape document version (if applicable)
- Description of the problem
- Steps to reproduce
- Expected behaviour
- Screenshots when useful

---

# 🚀 Feature Requests

Ideas are always welcome.

When suggesting a feature, please explain:

- What problem it solves
- Why it would benefit the framework
- Any alternative approaches you considered

---

# 📚 Documentation

Documentation improvements are just as valuable as CAD improvements.

If you find something unclear, please open an issue or submit a pull request.

---

# 🎯 Design Philosophy

Boxify follows a number of architectural principles.

Contributions should aim to preserve these principles:

- Parametric first
- Modular architecture
- Reusable components
- Stable references
- Single source of truth
- Separation of responsibilities

Whenever possible, new functionality should extend the framework rather than replace existing behaviour.

---

# ❤️ Thank You

Every suggestion, issue report or contribution helps make Boxify a better framework.

Thank you for being part of the project!
