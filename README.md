# 🏗 Boxify

**Boxify** is a **Parametric Electronics Enclosure Framework (PEEF)** for Onshape.

Instead of designing a new enclosure for every PCB, Boxify separates the electronics from the enclosure using a modular architecture centred around an **Adapter Plate**. This allows custom electronics enclosures to be generated quickly while keeping the design fully parametric and reusable.
