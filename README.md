# Boxify

Parametric Electronics Enclosure Framework (PEEF)

> From engineering to configuration.

Boxify separates electronics from the enclosure through reusable engineering libraries.

## Features

- PCB Library
- Adapter Plate
- Threaded Insert Library
- Parametric Box Base
- Parametric Box Lid
- KiCad integration (planned)
