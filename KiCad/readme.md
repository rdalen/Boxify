# KiCad Resources

These KiCad resources are provided to create PCB designs that match the mechanical definitions in the Boxify PCB Library.

## KiCad Templates

To use a Boxify KiCad template:

1. In KiCad, click **File > New Project from Template...** in the main menu.
2. Choose the **User Templates** source tab. This displays templates you have built or imported yourself.
3. Select one of the Boxify templates. Single-click an icon to view its description, layout constraints, or details.
4. Click **OK** once you have made your choice.
5. **Name and Save:** Provide a name for your design.
6. KiCad will automatically create a new project directory populated with pre-configured schematics, board layout, and design rules.

## KiKit Panelizing Plugin

To use one of the Boxify KiKit panelization configurations:

1. Open **PCB Editor** (standalone).
2. Start the **KiKit panelizing tool** by clicking the menu button.
3. In KiKit, import the desired panelization configuration, for example:
   `KiKit panelize 2x PCB w49x100mm.json`
4. Browse for the **Input file**.
5. Browse for the **Output file**.
6. Click **Panelize**.
