This is a template for a 23.5x23.5mm Panel PCB
1 - The schematic is already filled with the standard components and its footprints
2 - The Panel PCB has a size of 23.5mm*23.5mm to fit 16x PCBs as part of a 100 × 100mm production panel

Instructions for making a 100mm*100mm production panel with 16x w23.5x23.5mm Panel PCBs:
Open PCB Editor (standalone)
Start Kikit panelizing tool by clicking the menu button
Import in KiKit; C:\Dropbox\myKiCadFiles\MyKiKit Panel-Template/KiKit panelize 16x Panel PCB w23.5x23.5mm.json
Browse input file
Browse Output file
Click Panelize
