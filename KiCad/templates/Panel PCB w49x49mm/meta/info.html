2 - The Panel PCB has a size of 49mm*49mm to fit 4x PCBs as part of a 100 × 100mm production panel

Instructions for making a 100mm*100mm production panel with 4x w49x49mm Panel PCBs:
Open PCB Editor (standalone)
Start Kikit panelizing tool by clicking the menu button
Import in KiKit; C:\Dropbox\myKiCadFiles\MyKiKit Panel-Template/KiKit panelize 4x Panel PCB w49x49mm.json
Browse input file
Browse Output file
Click Panelize
